# Authentication & Authorization

RapidREST's included auth system utilizes industry standard JSON Web Tokens (JWT) with a powerful Roles Based Access Control (RBAC) authorization system, allowing
easy integration with existing authentication providers. The RBAC system has two levels of control; simple role checks per endpoint or fine-grained Access Control Lists per resource.
